# 🌤️ The Winstonian

The Winstonian is a modern weather application built with **Swift and SwiftUI**.  
It uses the **OpenWeatherMap API** to provide real-time weather information, location-based forecasts, city search, and detailed weather conditions.

## ✨ Features

- 📍 Current location weather
- 🔍 Search weather by city
- 🌡️ Celsius (°C) and Fahrenheit (°F)
- ⏰ Hourly weather forecast
- 📅 7-day weather forecast
- 💧 Humidity information
- 💨 Wind speed
- 🌡️ Feels-like temperature
- 🌫️ Air quality information
- 📊 Atmospheric pressure
- 👁️ Visibility
- 🌤️ Dynamic weather conditions and icons
- 🔄 Real-time API-based weather data

## 🛠️ Built With

- Swift
- SwiftUI
- MVVM Architecture
- OpenWeatherMap API
- Core Location
- Xcode

## 🏗️ Architecture

The application follows the **MVVM (Model-View-ViewModel)** architecture:

- **Model** — Represents weather and API response data.
- **View** — SwiftUI screens responsible for displaying weather information.
- **ViewModel** — Handles API calls, location updates, data processing, and UI state.

## 🌐 API

Weather data is provided by the **OpenWeatherMap API**.

> ⚠️ **Security:** Never commit your OpenWeatherMap API key directly to GitHub. Store sensitive keys securely and add local configuration files to `.gitignore`.
